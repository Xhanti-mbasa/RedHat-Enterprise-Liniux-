# Next Steps

The Red Hat Enterprise Linux Technical Overview introduces the basic tools and ideas needed to start working with Linux, but it is only the beginning.

Across this video series, we covered topics such as:

* Linux distributions and RHEL.
* Working from the shell.
* Built-in documentation.
* Linux filesystem directories.
* Basic file management.
* Editing files with Vim.
* Users, groups, and permissions.
* Managing software and updates.
* Networking.
* Systemd services.
* Application runtimes and newer image-based RHEL workflows.
* Red Hat management and vulnerability tools.
* The RHEL web console.

The best way to continue learning Linux is to keep using it. Commands become easier to remember when they are used to solve real problems rather than only memorized from a list.

Red Hat provides further training for people who want to move from a technical overview into hands-on system administration. One of the main next courses is **Red Hat System Administration I (RH124)**, which develops the core administration skills used by Linux system administrators.

For learners working toward Red Hat certification, these administration skills form part of the path toward the **Red Hat Certified System Administrator (RHCSA)** exam.

### Learning Takeaway

```text
The goal of this overview is not to memorize Linux. It is to understand the
core ideas, know which tools are available, and build enough familiarity to
continue into hands-on system administration and deeper Red Hat training.
```
